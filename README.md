
##Authors - Aaron OShea and Anthony Kalu

## Name
Finance Coach Application.

## Description
FinanceCoach is a personal finance assistant app that allows users to track expenses, view spending summaries, and ask an AI assistant questions about budgeting and saving. The app uses Firebase for authentication and the OpenAI API for AI-powered finance advice.

##Features
Users sign up/log in via secure Firebase authentication
Add delete and view monthly expenses
View monthly spending summaries and charts
Ask the AI chatbot finance related questions
Clean and friendly UI

##Technologies used
Android studio
Firebase authentication
Django
Open AI API
Android Emulator for testing


## Installation & Run
Clone this repository.
Open the cloned project in Android Studio.
Start an Android Emulator
Flutter pub get, flutter run in terminal in flutter app directory
The app will run on the emulator, sign up or login.

##Testing 
We used Android Emulator for testing.
Manual tracking of auth, expense tracking and AI functionality.

##Structure

app/ - main app code
Firebase auth - handles user login/registration
OpenAI - handles AI advice.
